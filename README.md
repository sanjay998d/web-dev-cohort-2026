## 🛠️ Built With
* **HTML5:** Semantic tags (`<header>`, `<main>`, `<section>`, `<address>`, etc.)
* **CSS3:** Basic styling for layout, spacing, and table formatting.

## 📋 Features
* **Semantic Structure:** High-level accessibility using proper document flow.
* **Responsive Tables:** Clearly defined headers and body for Experience and Education.
* **Interactive Elements:** Clickable email links using the `mailto:` protocol.
* **Organized Sections:** Visual separation using horizontal rules and clear heading hierarchies.
